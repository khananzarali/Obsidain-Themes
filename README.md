# Obsidian CSS Snippets

This repository contains custom CSS snippets for Obsidian to highlight the active line in various ways. 

## Snippets

### 1. ActiveLineBold.css
Makes the text on the currently active line bold.
- **File**: [`css/ActiveLineBold.css`](css/ActiveLineBold.css)

### 2. ActiveLineLightBackground.css
Adds a subtle light gray background with rounded corners to the active line.
- **File**: [`css/ActiveLineLightBackground.css`](css/ActiveLineLightBackground.css)

### 3. ActiveLinePurpleLeftLine.css
Displays a purple vertical line on the left side of the active line.
- **File**: [`css/ActiveLinePurpleLeftLine.css`](css/ActiveLinePurpleLeftLine.css)

### 4. ActiveLinePurpleRightLine.css
Displays a purple vertical line on the right side of the active line.
- **File**: [`css/ActiveLinePurpleRightLine.css`](css/ActiveLinePurpleRightLine.css)

## How to Install

1. Download the desired `.css` snippet(s) from the `css/` folder.
2. Open Obsidian and go to **Settings** > **Appearance**.
3. Scroll down to the **CSS snippets** section.
4. Click the folder icon to open your snippets folder (usually located at `<vault>/.obsidian/snippets`).
5. Move the downloaded `.css` files into this folder.
6. Return to Obsidian and click the **Refresh** icon in the CSS snippets section.
7. Toggle on the snippet(s) you wish to use.

## Note
Ensure you don't enable conflicting snippets at the same time for the best experience.
